# 统一视觉概念与创意补全

## 目标

在产品事实准确的前提下，让单张图有明确创意，让整套副图属于同一个品牌世界。业务卡是事实底座，不是画面上限；选填项为空时，Agent 应完成合理的商业创意，而不是退化为模板图。

## 先区分两类信息

### 不得自行补造的商品事实

- 材质、成分、容量、尺寸、数量和订单内容。
- 性能参数、兼容性、认证、检测结果、功效和安全等级。
- 奖项、评分、销量、排名、专利和其他可核验声明。
- 产品真实结构、标签、Logo、包装文字和颜色。

没有用户证据时，不得把这些内容写入文案或用画面暗示为真。

### 应当主动补全的商业创意

- 目标人群假设和购买动机。
- 产品给生活带来的情绪价值与使用节奏。
- 场景、环境道具和人物状态；道具必须明显属于环境，不能暗示随订单附赠。
- 品牌气质、色彩系统、材质语言、镜头、灯光、构图和景深。
- 视觉隐喻、叙事方式、营销文案和利益点表达。

## 三方向内选

整套副图生成前，Agent 在内部至少提出 3 个明显不同的方向，例如：

1. 生活方式叙事：从真实人群和使用时刻建立共鸣。
2. 产品设计语言：从材质、形态、结构与品牌气质建立高级感。
3. 卖点视觉隐喻：把已确认功能转译为时间、温度、空间或动作的视觉故事。

方向不能只是把背景颜色换掉。比较以下四项后，自主选出一套：

- 与产品外观和品类是否匹配。
- 是否适合目标国家和电商站点。
- 是否能把已确认卖点转化为买家利益。
- 是否能延展到本轮所有副图，同时让每张图各不相同。

除非用户要求，不展示三个内部草案，只在生成规划中展示最终选中的方向及选择理由。

## 统一视觉概念卡

选中方向后，建立一张内部概念卡：

```text
【概念名】简短、可记忆
【目标人群假设】基于品类和站点的合理假设
【买家情绪价值】产品让用户感到什么
【核心创意句】不是参数复述，而是本套图的叙事主张
【品牌气质】3～5 个形容词
【主色与辅助色】来自产品、品牌和使用情绪
【材质与环境语言】台面、背景、道具和空间的统一逻辑
【摄影与灯光】主光、色温、镜头距离和景深语言
【文案语气】简洁、温暖、专业、冒险感等
【贯穿母题】在多张副图中变化出现的光线、形状、时间线或动作
【事实禁区】本产品不能新增或暗示的事实
```

## 基础调性合同（强制冻结，场景保持开放）

概念卡完成后，在逐图规划和生图之前，把下列视觉变量冻结为可检查的合同；不得只写“科技感”“高级感”“运动感”等抽象词：

```text
【整体明暗】高调明亮／中间调／低调暗色，只选一个主区间
【色彩比例】主背景色、产品色、辅助色、强调色的大致面积比例
【色彩分级】冷暖倾向、饱和度与对比度范围
【字体合同】字体家族、三层字号关系、文字色和安全区逻辑
【品牌质感】产品高光、阴影、材质清晰度和整体精致度
【类型分工】每类图片根据元提示词分别承担什么表达重点
```

- 元提示词决定每类图片的场景、布局、人物、窗口与构图；基础调性合同只统一明暗倾向、冷暖、配色、色彩分级、字体和产品质感。不得用基础调性合同覆盖元提示词的类型特征。
- 第一张通过的副图可以成为调性主控图。后续副图参考它的色调和品牌质感，但不得复制它的具体环境、台座、跑道、办公室、人物或构图。
- 用户明确修改风格时，先更新视觉合同，再重算受影响的逐图规划；不得只改当前单图而让整套继续分裂。
- 复合风格在整套层面分工落地。例如“运动白领”可以由英雄图承担人物张力、场景图承担真实运动、展示图承担利落专业、细节图承担精密科技；不要求每张图都同时出现办公室和跑道。

## 从事实到利益再到画面

不要把业务卡字段直接变成排版。使用以下链路：

```text
已确认事实 -> 买家利益 -> 生活意义 -> 视觉故事 -> 最终文案
```

示例：

```text
保温和保冷 24 小时
-> 一整天不必反复更换饮品
-> 从清晨出门到夜间收工仍保持适合的温度
-> 同一只杯子跨越晨光与夜色的连续时间叙事
-> FROM FIRST SIP TO LAST.
```

最终文案可以创作，但支撑它的事实必须来自业务卡。

## 套图统一而不重复

- 展示图：建立产品性格和设计语言，不承担信息堆叠。
- 卖点图：把一个购买理由视觉化，不只是参数左右排版。
- 英雄图：把统一概念压缩成最有冲击力的广告画面。
- 细节图：用微距和结构回答真实购买问题，同时延续材质与色彩语言。
- 场景图：让目标人群在真实时刻自然使用产品，完成情绪落地。

五张副图共享基础明暗倾向、冷暖、品牌配色、色彩分级、字体家族和产品质感；场景、背景材质、人物、道具、镜头、灯光方向、节奏和叙事方式应根据各自元提示词主动变化。禁止连续复用相同办公室、跑道、台座、产品位置、左右文字或图标模板。

## 提示词的发挥空间

提示词必须锁定：产品事实、品牌识别、图片商业任务、必要文案、尺寸和禁止项。

提示词不应写死所有非事实型细节。对于环境层次、自然道具关系、光影过渡、人物微表情和次要装饰，描述意图与气质即可，让生图模型在安全边界内完成视觉设计。

## 创意质检

除常规事实质检外，再检查：

1. 去掉文案后，画面是否仍能表达本图任务。
2. 文案是否把参数转化成买家利益，而不是照抄字段。
3. 画面是否具有产品专属感，换成任意同类商品后是否仍完全成立；如果是，说明创意过于通用。
4. 本图是否与其他副图属于同一品牌世界，又没有复用同一种模板。
5. 所有主动补全是否只属于商业创意，没有被误写成商品事实。
6. 与调性主控图缩小并排后，基础明暗、冷暖、品牌配色、字体和产品质感是否协调；场景和背景不同不构成失败。
7. 当前图片是否清楚完成本类型元提示词的任务，而不是机械重复其他图片的环境与版式。
