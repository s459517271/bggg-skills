# 产品业务卡

业务卡采用“固定核心字段＋品类动态字段”。首次触发时先发送核心业务卡；用户已提供的字段要自动带入，不要求重复填写。

```text
【产品图｜必填】上传白底图、多角度图、细节图、包装图或清晰随手拍
【产品名｜必填】
【产品品类｜必填】用于事实判断、目录和文件命名，例如宠物用品、厨房用品、护肤品

【品牌名｜选填】
【目标国家／电商站点｜选填】默认 Amazon 美国站
【生成语言｜选填】默认英语
【商品特征｜选填】颜色、形状、结构、规格、材质和真实功能
【卖点热词｜选填】希望重点表达的卖点热词及其证据（对应元提示词【卖点热词】，会注入提示词并生成对应文案）
【目标用户｜选填】
【使用场景｜选填】
【产品尺寸／容量｜选填】
【包装和订单内物品｜选填】实际包含的数量、包装、配件和赠品
【品牌色、字体和视觉偏好｜选填】
【参考图｜选填】只用于参考版式、构图、色调或氛围
【竞品链接／ASIN｜选填】用于拆解同品类竞品套图和 A+ 信息架构，只借鉴版式与买家问题
【负面词汇｜选填】不能出现的词、品牌、人物、道具、风格或表达（对应元提示词【负面词汇】，绝对不允许出现在生成结果中）
【补充信息｜选填】认证、测试、合规限制或其他注意事项
```

用户填写竞品链接或 ASIN 时，读取 [`competitor-benchmark.md`](competitor-benchmark.md) 做受控拆解，并把竞品洞察并入统一视觉概念。用户未提供任何参考时，Agent 在第二步询问是否需要联网找参考，同意后再检索同品类优秀范例，不擅自联网。

## 按品类动态完善

拿到产品品类后，判断哪些字段会影响产品真实性、画面内容或文案。只追加相关字段，不把下面所有问题一次性发给用户。

### 护肤、美妆、个护

- 质地、颜色、容量、使用部位和使用方式。
- 用户可提供的真实成分、配方或检测依据。
- 可表达与不可表达的功效词。
- 包装形态、泵头／滴管／刷头等结构细节。

### 食品、饮品、营养补充品

- 净含量、口味、包装数量和食用方式。
- 真实配料、营养信息、过敏原和储存要求。
- 保质期、认证或健康相关表述的证据边界。

### 电子产品、数码配件、小家电

- 尺寸、材质、接口、供电方式、电池或功率。
- 兼容型号、连接方式和订单内配件。
- 可验证的性能参数、防护等级和认证。

### 服装、鞋靴、箱包与配饰

- 面料、颜色、尺码、版型和关键工艺。
- 模特穿着要求、目标身形和展示角度。
- 拉链、口袋、肩带、鞋底等需要锁定的结构。

### 家居、厨房、收纳与家具

- 长宽高、容量、材质、承重和适用空间。
- 安装方式、清洁方式、套装数量和订单内零件。
- 与常见设备或空间的真实兼容关系。

### 宠物用品

- 适用宠物种类、体型、年龄和使用方式。
- 材质、尺寸、容量、安全结构和清洁方式。
- 宠物、人物与产品之间的真实比例。

### 工具、运动与户外用品

- 材质、尺寸、承重、耐候或防水参数。
- 使用环境、安全限制、安装方式和订单内配件。
- 只有实测或证据支持时才表达耐用、抗压、防水等性能。

### 其他品类

根据产品结构生成最多 3～5 个补充问题。优先询问会影响以下内容的信息：

1. 产品是否会画错。
2. 订单内容是否会误导。
3. 卖点文案是否有证据。
4. 人物、场景、尺寸或使用动作是否真实。

## 收卡规则

1. 产品图、产品名、产品品类缺一不可。
2. 产品品类过于宽泛时，给出一个更具体的候选名称，请用户确认；不要静默决定，因为它会进入目录名和文件名。
3. 选填项可留空，不要一次性追问所有空字段。
4. 目标用户、使用场景、品牌色、字体和视觉偏好等创意型选填项留空时，默认由 Agent 根据品类、目标站点和已确认卖点主动补全，并在统一视觉概念中标记为“创意假设”；只有不同选择会实质改变用户意图时才追问。
5. 如果用户只给了图片，先根据可见内容整理“待确认的产品事实”，再询问产品名和品类。
6. 动态补充字段最多一次追问 3～5 个关键问题；只追问影响事实准确、合规或用户明确意图的信息，不为普通创意选择反复打断用户。
7. 业务卡确认后，才进入图片类型选择。

## 默认商业假设预填

业务卡确认后，Agent 要主动把品类常识补成可执行的商业假设，而不是等用户填空。所有预填内容按下面三类分账，并在生成规划中标注来源：

**可主动补全（标记为“创意假设”）**

- 目标人群、使用场景、情绪价值、视觉风格、镜头和文案语气。
- 基于品类的典型购买理由和买家决策问题。
- 画面内的环境道具、人物状态和视觉隐喻（不暗示附赠）。

**需用户确认（先给候选，不静默决定）**

- 会影响卖点主次排序的购买理由。
- 与事实接近但证据不足的表达，例如“适合送礼”“适合家庭多人使用”这类依赖用户意图的判断。
- 品牌色、字体和视觉偏好的具体选择。

**禁止编造（缺失即留白或调整画面）**

- 材质、成分、容量、尺寸、性能、认证、兼容性、包装数量和订单配件。

示例：保温杯品类（Amazon 美国站）的默认预填

- 可主动补全：通勤、办公室、户外场景；全天保温带来的“从出门到回家温度不变”情绪价值；携带尺寸与杯架兼容的镜头语言。
- 需用户确认：卖点排序建议为“保温时长 → 材质安全 → 密封防漏 → 便携尺寸”，但最终以用户业务卡为准。
- 禁止编造：24 小时保温、304 不锈钢等参数只能来自用户证据；杯盖是否密封防漏、是否可拆洗、是否适配车载杯架均需用户确认或标注为创意假设。
