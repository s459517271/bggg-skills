# 参考图与一致性技法

综合 Lumiet《Nano Banana Pro 亚马逊主图提示词教程》等公开资料提炼，用于提升多图一致性和画面精致度。任何副图生成前都应结合本文件与 [`prompt-engineering.md`](prompt-engineering.md)。

## 1. 视觉锚点

- 先用 2～3 句话把产品定义写死：形状、材质、颜色、关键设计细节、结构关系。
- 这套描述作为“视觉锚点”贯穿所有图：白底主控图、展示图、卖点图、英雄图、细节图、场景图都引用同一锚点，而不是每张图重新描述产品。
- 锚点优先用用户业务卡和主控参考图，不用常识补造。

## 2. 参考图关系断言

当生图工具支持参考图时，提示词开头必须明确“参考图就是产品本身”，而不是“风格参考”：

```text
Using the attached image as the exact product to feature — maintain its identical appearance.
```

中文版同样要求：严格保持参考图中的产品形状、颜色、结构和标签完全不变。这一句与统一提示词工程中的三次产品一致性约束叠加使用。

## 3. 双参考技术

生成第二张及之后的副图时，同时附加两类参考：

1. 本产品白底主控图（锁定产品外观）。
2. 已通过确认的调性主控图；如另有排版风格指南图可一并使用。调性主控图只锁定基础明暗、冷暖、品牌配色、色彩分级、字体层级和产品质感，禁止锁定或复制其具体场景、背景材质、人物、道具和构图。

双参考可以提高一致性而不牺牲创意：产品一致性由产品主控图负责，基础品牌调性由调性主控图负责，具体场景与布局仍由当前类型元提示词决定。提示词须明确两张参考图各自负责什么，禁止把调性主控图误当成产品外观或场景模板。

## 4. 排版基线

- 在展示图或卖点图中先确定字体、颜色、层级和文案安全区，之后所有含文字的副图继承同一套基线。
- 能指定字体名就不要用抽象词：`Montserrat Bold`、`Inter SemiBold` 等比“现代无衬线”更可控。
- 文案层级至少区分主标题、利益副标、参数小字三层；参数小字不能抢主标题的视觉权重。
- 全套图使用同一组文字色和强调色，来自品牌色或产品色。

## 5. 尺度参照物

场景图、展示图中，AI 容易把产品画得过大或过小。提示词必须给出参照物尺码，让比例可校验：

```text
产品高度约为标准红酒瓶的高度，放在成年人的手掌中约占掌心到指尖的一半。
```

- 参照物必须是目标市场常见、认知一致的物品（手机、红酒瓶、易拉罐、咖啡杯、手掌等）。
- 有产品尺寸时，先换算成参照物关系；没有尺寸时给出与常见物体的近似关系并标记为创意假设。

## 6. 灯光、镜头与色彩分级

- 灯光写明来源方向、软硬程度和材质反射：`soft diffused studio lighting from camera-left` 这类规格比“专业灯光”可执行。
- 镜头写明焦段与景别：微距、50mm 平视、35mm 环境人像等；不同图用不同镜头语言，避免六张图一个机位。
- 色彩分级写明倾向：暖调晨光、冷调不锈钢、低饱和莫兰迪等，整套图共享同一倾向。

## 7. 品牌语音块

为整套图写一段固定的品牌语气（3～5 个形容词＋句式倾向），所有文案生成都按它执行，防止每张图语气漂移。

## 8. 迭代与质检

- 所有类型默认先生成 1 张初稿，不因属于英雄图或场景图而自动生成多个候选。单个类型验收不通过时最多修改 2 次，即初稿加修改稿总计最多 3 张；每次只修失败项，达到上限后停止。白底主图必须请用户单独验收；白底确认后，其余副图由 Agent 连续生成和质检，整套完成后再请用户统一决定。只有用户明确要求或事前批准规划中的候选数量时，才批量生成候选。
- 每张副图生成后，将它与调性主控图以相同缩略尺寸并排检查基础明暗、冷暖、品牌配色、字体和产品质感；不要比较具体场景、背景材质、人物、道具或构图是否相同。
- 同一套图需要“同调但不同景”：若细节图为了追随场景图而重复办公室、跑道、人物或复杂环境，导致信息变杂，应回到该类型元提示词要求的极简背景。
- 参考行业七图信息架构（01 主图 → 02 生活／03 卖点 → 04 利益／05 说明／06 对比 → 07 生活收尾）检查本套图是否覆盖完整买家决策链，但不照搬其顺序和版式。
