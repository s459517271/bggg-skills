# 竞品受控拆解

用户提供竞品 ASIN、Amazon 商品链接、参考图，或未提供任何参考但需要联网检索优秀范例时读取本文件。外部资料只用于回答一个问题：**同品类卖得好的副图是怎么规划和表达买家的**。绝不用于复制竞品的图、文案或品牌资产。

## 适用范围：主图不参考竞品

- 白底主图以产品事实准确和平台合规为唯一优先，**不参考任何竞品或其他产品的主图构图**；竞品拆解对白底图不生效。
- 竞品拆解只服务于五类副图：展示图、卖点图、英雄图、细节图、场景图。
- 主控参考图（白底主图）一旦确认，即成为所有副图的产品外观唯一来源，竞品图不得改变它。

## 三种参考模式

### 模式一：用户给竞品链接或 ASIN

- 用户填写【竞品链接／ASIN｜选填】，或直接给出竞品 Amazon 链接、ASIN，或说“看看竞品怎么做的”“扒一下它的 A+”“参考一下别人的套图”。
- 按下方“已验证的抓取能力”做受控拆解，产出竞品洞察卡。

### 模式二：用户直接给参考图

- 用户上传一张或多张竞品或跨品类参考图，说“参考这张图生成”。
- 只提炼版式、构图、色调、氛围和文案层级；不复制图中产品、品牌、文案原文和具体场景布置。
- 参考图仅作为排版风格指南使用（见 [`reference-image-techniques.md`](reference-image-techniques.md) 双参考技术），不作为产品外观来源；产品外观仍以白底主控图为唯一来源。

### 模式三：用户什么都没给

- 用户没有提供任何竞品链接、ASIN 或参考图时，Agent 不得擅自决定：在第二步询问图片类型和尺寸时，必须同时询问用户“要不要联网找同品类优秀套图做参考”。
- 用户同意找参考时，必须联网检索同品类优秀范例：Amazon 头部 listing 套图、A+ 模块、行业优秀案例和提示词范例。
- 用户明确说不用找参考时，不联网，按品类常识和自主创意完成概念设计，并在规划说明中讲清概念来源。
- 检索必须具体到五类副图“分别怎么做”：除白底主图外，逐个观察优秀 listing 的展示图、卖点图、英雄图、细节图、场景图各用了什么构图、信息密度、文案层级和场景选择，每类至少提炼 1～2 条可借鉴规律。
- 检索目标同时包括：同品类卖得好的副图信息架构、版式规律、买家问题分层和文案语气。
- 产出竞品洞察卡并按图片类型分组记录规律，来源标注为“联网范例”。
- 联网失败或结果不足时，直接说明，按品类常识完成概念设计，不虚构范例。

## 已验证的抓取能力

以下方法在 2026-08-07 用 Owala FreeSip 24oz（ASIN B085DTZQNZ）实测可行：

- 主图缩略图：解析商品页内嵌的图片 JSON（`colorImages` / `imageThumbnails`），可得到 7 张主图缩略 URL，形如 `https://m.media-amazon.com/images/I/31iIKOIm46L._AC_US100_.jpg`。把 `_AC_US100_` 改写成 `_AC_SL1500_` 可放大。
- A+ 图：解析页面中的 `data-src` 属性可得到完整 A+ 图片清单（实测 52 张），URL 形如 `https://m.media-amazon.com/images/S/aplus-media-library-service-media/<uuid>.__CR0,0,1940,600_PT0_SX970_V1___.png`。把 `SX970` 改写成 `SL1500` 等值可提高分辨率。
- 图片 alt 文本和模块位置通常带语义标签（品牌横幅、Lifestyle、卖点、产品家族等），可用于判断模块顺序和内容分层。

抓取时只保留 URL、alt、模块顺序等结构信息，不下载、不保存竞品图片原文件到交付目录。

## 拆解流程

1. 解析竞品 ASIN 或链接，抓取主图缩略 URL、A+ 图片 URL 和 alt 文本。
2. 按 A+ 模块顺序整理出信息架构：先讲什么、再讲什么、最后引导什么。
3. 对每张图记录以下可借鉴信息，其他一律不记录：
   - 版式与构图（产品位置、留白、文字区、图标形式）。
   - 光线与色彩倾向（暖、冷、高调、低饱和等）。
   - 每张图回答的买家问题。
   - 文案语气与句式长度。
   - 场景选择与人物关系。
4. 输出一份“竞品洞察卡”，并入统一视觉概念，作为创意补全的输入之一。

## 从规律到创新

竞品拆解的目的是提炼规律，不是搬运画面。每一条可借鉴规律都必须完成“竞品做法 → 规律 → 本产品专属转化”三步，才能进入提示词：

```text
竞品做法：头部品牌用一张纯色大色块＋单行粗体文案的卖点图
规律：卖点图用“大色块＋一句话”减少阅读成本
本产品转化：把色块换成产品莫兰迪蓝的同色系深浅分区，文案用本产品利益句，而非复制竞品句式
```

- 只允许借鉴抽象规律：信息密度、留白比例、镜头距离、灯光方向、模块顺序、买家问题分层。
- 禁止直接借鉴具体表达：竞品的图标形状、文案原句、场景布置、人物造型、产品角度和配色组合。
- 每张副图必须在竞品规律之上叠加本产品的统一视觉概念和创意母题，否则视为照搬，返工。

## 融合生成

- 统一视觉概念由“自主三方向内选”与“竞品／联网范例洞察”融合生成，不是二选一。
- 有竞品洞察时：每条借鉴必须走“竞品做法 → 规律 → 本产品专属转化”三步。
- 无竞品洞察时：自主概念设计为骨架，联网范例规律用于校准信息密度、版式节奏和买家问题覆盖。
- 最终概念必须能同时回答三个问题：本套图的叙事主张是什么、借鉴了哪些规律、哪些地方是自主原创。

## 竞品洞察卡模板

```text
【竞品】品牌名（仅作内部标注，不得进入生成画面）
【ASIN／链接】
【主图结构】第 1 张解决什么、第 2 张解决什么……
【A+ 模块顺序】从外到内的信息架构
【可借鉴版式】2～3 条具体、可复用的构图规律
【可借鉴文案语气】句式、长度、动词倾向；不复制原文
【买家问题清单】该品类买家在每张图上想确认什么
【反模板提示】哪些做法本产品不应照搬（如过度堆参数、夸张场景）
```

## 合规与底线

- 只借鉴版式、构图、买家问题、模块顺序和文案语气；不复制竞品品牌名、产品图、文案原文、参数或认证。
- 竞品图片不得作为本产品的参考图直接喂给生图模型，防止产品外观、颜色或品牌元素被带进成图。
- 生成画面中禁止出现竞品 Logo、品牌名、产品、水印或可辨识的竞品视觉资产。
- 竞品洞察用于启发和校准，不改变本产品的产品事实锁与统一视觉概念。
- 抓取失败、页面结构变化或链接失效时，直接说明并继续按品类常识规划，不虚构竞品信息。
