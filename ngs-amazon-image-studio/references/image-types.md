# 六类图片边界

## 1. 白底图 `white-background`

合规、准确地展示实际售卖的商品。纯白背景，不承担卖点解释和氛围营造。

## 2. 展示图 `showcase`

以产品为中心展示正面、背面、侧面、45°角、包装、套装内容或整体形态。允许简洁摄影背景和产品名，但不安排人物使用动作，不堆叠多个卖点。

## 3. 卖点图 `selling-point`

用短文案、图标、标注线、局部放大或结构示意解释 1 个核心卖点，最多 3 个强相关卖点。只表达有业务卡依据的内容。

## 4. 英雄图 `hero`

商品为绝对主角，通过强透视、戏剧灯光、品牌色和精炼营销文案制造视觉冲击力。英雄图是副图或广告主视觉，不是 Amazon 白底主图。

## 5. 细节图 `detail`

展示材质、纹理、接口、做工、结构、包装或使用质地等买家在普通全景图中看不清的真实细节。每个特写必须能回答一个具体购买问题。

## 6. 场景图 `lifestyle`

展示谁在什么环境下如何使用产品，让买家理解使用情境和真实比例。人物只在有必要时出现，不能抢夺产品主体。

## 重叠处理

- 有人物但核心是强视觉广告：英雄图。
- 有人物并强调真实使用：场景图。
- 只有产品与包装的摄影陈列：展示图。
- 解释功能、结构或利益点：卖点图。
- 放大材质或工艺：细节图。
- 用户要求尺寸、成分或使用步骤时，先判断它应归入卖点图或细节图，不新建第七种类型。
