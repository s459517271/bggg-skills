# Gemini 与 Flow 操作 SOP

## 共同原则

- 使用用户已登录的Chrome配置；不要读取cookies、密码或浏览器存储。
- 每次提交前核对`账号别名＋Chrome配置名＋页面可见身份`。多账号只切换用户已授权且已登录的配置，不自动登录、不创建账号、不使用隐身窗口规避限制。
- 上传文件前读取当前浏览器的文件上传说明。
- 每次生成前确认输入角色、9:16、片段编号和目标记录。
- 提交生成属于用户已授权的工作流动作；购买积分、开启自动充值或升级订阅必须另行确认。
- 额度、恢复周期、模型名称、片长和单次成本会变化，始终以当次界面为准。

## Gemini 专业视频入口

1. 打开 Gemini 后，从左侧明确点击`Videos/视频`。直接访问 `/videos` 可能仍显示为 `/app`，只以页面出现`制作视频`、文件上传和画幅控件为进入成功证据。
2. 为每一条任务建立干净的视频任务；不要用普通聊天代替，也不要复用上一条任务残留的附件或上下文。
3. 先打开画幅菜单，选择`Portrait/肖像（9:16）`，再读取该单选项的`aria-checked=true`。界面内部可见文字偶尔仍残留“横屏（16:9）”，不得据此覆盖已验证的单选状态；提交前再次回读。
4. 按顺序逐张上传：本段整张9:16九宫格、产品图；连续段再加入上一段真实尾帧。每上传一张后等待上传完成，再传下一张；不要在一次文件选择器中多选全部图片。
5. 缩略图出现只是本地预览，不是提交成功证据。提交后必须看到“我正在生成您的视频/正在生成您的视频”才算任务被接受。若返回“请上传图片，以便我生成视频”，说明附件没有随请求提交，不得继续等待或计为额度生成。
6. 若失败对话中的文件上传按钮不再打开文件选择器，新开一个干净的 Gemini 标签页，等待页面加载，重新点击左侧`Videos/视频`，再按“选9:16 → 逐张上传并等待 → 填提示词”的顺序重做。
7. 按专业入口当次显示的实际单段时长写完整视频提示词。必须在开头、输出规格段和硬约束段三次写明：`VERTICAL PORTRAIT, aspect ratio 9:16 (width:height), 1080×1920 orientation`，并禁止16:9横屏、方形、黑边和旋转。
8. 提交前核对：专业视频页、附件数量正确、完整提示词已填入且三次强调9:16、`肖像（9:16）`仍为选中状态。
9. 出现“视频已准备就绪”后下载。自动下载不可用时可让用户在当前成片页手动保存；保存完成后由 Codex 立即移动并重命名到统一输出目录，再用`ffprobe`验证：文件可读、时长符合提交时界面配置、实际宽小于高且宽高比接近9:16。任一项不符合即在文件名标记`不合格`、不上传飞书成品字段并重做。
10. 达到限制时进入左下角`设置 → 使用限制`，同时读取当前使用百分比、短周期恢复提示、周额度使用百分比和周恢复提示。恢复提示缺少日期或时区时原样记录，不自行换算成时间戳。

Gemini额度优先使用。若专业入口无法可靠选中9:16，停止在 Gemini 重试并切换 Flow。不要假设固定每日次数或24小时刷新；账户页面可能显示按小时恢复和周上限。

### 使用限制页面的记录规则

- 用户观察到“一个会话约3个视频、约5小时恢复”时，只记作经验值，不写成固定限额或定时规则。
- 只有页面同时给出可确定的日期、时间和时区，才可转换后写入 Base 的`下次运行时间`。
- 页面只显示一个时刻、`明天再来`等不完整信息时，把整段原文写入`最后成功步骤`，`下次运行时间`留空。
- 记录短周期和周限制两组信息，避免把“周额度仍有余额”误判为“当前视频额度可立即使用”。
- 同一轮连续成功提交3个视频后，把Gemini记为`疑似耗尽（3次经验阈值）`并优先切换Flow；不要为了测试额度提交第4个无关任务。只有页面或生成返回明确拒绝时才记为`已耗尽`。

## Google Flow

打开用户指定项目。默认预设：

```text
Video
9:16
1x
10s
Omni Flash
```

### Flow 实测提交 SOP

1. 用顶部`Add Media → Upload media`把九宫格和产品图逐张上传到当前项目素材库；等待每张素材在画布中出现后再继续。
2. 在底部提示框点击`+`，从素材选择框一次选中一张素材并点击`Add to Prompt`；重复操作，直到提示框上方出现计划数量的素材 chip。不要把“素材已上传到项目”误当成“素材已加入 Ingredients”。
3. 打开配置面板并回读：
   - `Video`已选中；
   - `Ingredients`已选中；
   - `9:16`已选中；
   - 生成数量为`1x`；
   - 模型、时长和单次 credits 与本次计划一致。
4. Flow 的提示词输入框是 Slate 编辑器。浏览器自动化的`fill`、`type`或普通粘贴可能只让文字显示在 DOM 中，但内部状态仍为空；此时创建按钮保持`aria-disabled=true`，强行点击会报`Prompt must be provided`。
5. 遇到上述假输入时：
   - 点击 Flow 自带的`Clear prompt`或刷新项目，恢复干净编辑器；
   - 重新挂载 Ingredients；
   - 聚焦空白编辑器后，用真实键盘按键序列输入完整提示词；可先输入单个测试字符，只有创建按钮变为`aria-disabled=false`才说明输入通道有效；
   - 清除测试字符，再用同一真实按键通道输入完整提示词；
   - 回读编辑器文本长度、开头、结尾和创建按钮状态，确认完整内容进入内部状态后再提交。
6. 不要为了让按钮变亮把完整提示词临时替换为一句短提示词。每条 Flow 提示词仍需包含参考图职责、输出规格、人物/场景、镜头、逐秒时间轴、声音和硬约束。
7. 提交成功后提示框会清空，画布出现带进度的生成卡片；旧的`Prompt must be provided`通知可能仍残留，只以新生成卡片和后续视频缩略图作为本次任务证据。
8. 视频缩略图出现后打开详情；`Download`可能短暂为 disabled，等待其变为可用再点击。
9. Chrome 下载可能先落为`Downloads/.com.google.Chrome.*`隐藏临时文件。用`file`确认是 MP4，再用`ffprobe`读取宽高、时长和音轨；验收通过后移动并按产品名、片段、入口、画幅和时长重命名到统一输出目录。

## 下载后的后处理

Gemini 可见星形水印、音轨保留和成品验收统一按 [postprocess-sop.md](postprocess-sop.md) 执行。禁止使用 `delogo`、模糊、马赛克、贴图或裁边冒充去水印。不可见的 SynthID 不属于画面水印，不尝试移除。

### Ingredients 模式

用于必须同时上传多个参考素材：

```text
图1：第1段真实尾帧（第2段必备，最高优先级）
图2：本段整张九宫格
图3：产品主参考图
图4–5：必要的产品角度或人物身份参考
```

提示词必须声明尾帧是本段起点，九宫格只是时间顺序参考，不得生成拼贴、边框或编号。

### Frames 模式

用于需要明确首尾画面的片段：

```text
Start：第1段单独准备的精确首帧，或上一段真实尾帧
End：单独准备的精确目标尾帧（不要使用整张九宫格）
```

当产品外观已经准确嵌入Start/End帧且另有独立目标尾帧时使用Frames；需要额外产品图或九宫格时改用Ingredients。

### Flow额度

- Flow积分按账户当前订阅和结算周期管理，与Gemini聊天使用限制分开。
- 每次从配置面板读取单次生成成本和剩余积分。
- 积分不足时可询问用户是否购买一次性AI Credits或设置自动补充；未确认前不要进入付款或开启自动充值。

## 路由顺序

```text
按优先级和最后使用时间轮询所有可用Gemini账号
当前Gemini账号受限 -> 记录原文并切下一个Gemini账号
所有Gemini账号不可用 -> 按相同规则轮询有积分的Flow账号
Flow用完或不足 -> 检查下一个Flow账号；随后复查已到检查时间的Gemini账号
全部入口不可用 -> 记录最早恢复时间/余额，询问是否安排续跑或购买积分
任一Gemini恢复 -> 回到Gemini继续处理未完成片段
```

账号登记、同任务账号粘性、轮询和日志格式见 [account-routing.md](account-routing.md)。
